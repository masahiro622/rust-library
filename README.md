# Rust用 競技プログラミングライブラリ

AtCoder などの競技プログラミングでの使用を想定した Rust 用ライブラリです。

> [!NOTE]
> 作者個人が使うためのライブラリで、他の方が使うことはあまり想定していません。
> そのため構成やドキュメントはあまり整理されておらず、予告なく破壊的変更(関数名・引数・ファイル構成の変更など)を行うことがあります。

## 生成AIの使用について

本ライブラリのコードの一部は、生成AIを利用して作成しています。

AtCoder 等で本ライブラリのコードを使用する場合は、各コンテストのルールに従い、
提出コード内に本リポジトリへのリンクを記載するなどの対応をしてください。
